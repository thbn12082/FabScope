# Third-party assets

The 3D view uses **Three.js 0.180.0**, MIT licensed. The library and OrbitControls are vendored locally so the application does not fetch code/assets from a CDN at runtime.

- Source package: https://registry.npmjs.org/three/-/three-0.180.0.tgz
- License: [THREE-LICENSE.txt](src/fabscope/ui/vendor/THREE-LICENSE.txt)
- Original file and archive hashes: [manifest.json](src/fabscope/ui/vendor/manifest.json)
- Official installation/import documentation: https://threejs.org/manual/pages/installation.html
- Official OrbitControls reference: https://threejs.org/docs/pages/OrbitControls.html

The factory geometry and interface in `factory.js` are authored for this project. No external factory model, industrial design file, texture dataset or equipment trace is used.
